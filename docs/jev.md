# Jev：现场反应和对话留白

配置服务端 `.env` 中的 `TYPESAFE_API_KEY` 后自动启用，`JEV_ENABLED=0` 恢复原有导演逻辑。
默认模型 `jev-latest`，可用 `TYPESAFE_DEFAULT_MODEL` 覆盖。密钥不发送到浏览器。

每次完整用户发言并行判断意图、安静偏好和轻反应；语音主链不等待 Jev。
意图仅作为上下文提示。安静偏好持续到明确恢复交流；低置信度保持原偏好。
窗口注视、注视用户和微笑通过现有 directive 通道呈现，最多每八秒一次。
需要等待说话/播放结束、地图关闭、转场结束和显式动作释放；六秒过期即丢弃。
不进行逐帧网络调用，也不在沉默时循环生成台词或事件。

回复结束后，Jev 判定 yield/quiet/continue。只有高置信度 continue 才调用现有
台词生成器；直接问句始终让出话轮。播放完成确认启动停顿，最多补充一次，
打字、语音活动、转场或断线使结果失效。原有内容过滤和过期限制仍执行。
Jev 的问题相互独立，跨字段约束由代码处理。

请求超时 2200ms，不自动重试：现场反应保持原状，续话让出话轮。
`confidence` 是分布统计值，不是正确率；当前 0.8/0.85 门槛是保守初值，尚未校准。
日志只输出耗时和决策，不输出密钥。会话上下文会发送到 TypeSafe 官方 API。

离线回归：`pnpm test`。付费真实接口探测：`pnpm test:jev`。
探测仅验证接口及中文判断；实际对话自然度、播放时序和设备观感需真实交互验收。
