# 可选前景：门廊 / 海边步道首批验证

- 新场景先按已有随机站位生成构图草图，Mira 占画面约60%。
- 仅明确的木质门廊/廊下/门框机位启用近柱与屋檐；开阔步道、普通街道及明确无前景的描述不生成额外前景。
- 同一母图经分割提案、暖木颜色与规划区域约束得到透明 PNG；前景 RGB 来自母图，非独立重绘。
- 遮罩检查：面积、人物保护区、计划区域。不合格则保留完整母图，不发布错误前景。
- 背景仅在分离区域及边缘修补。生图编辑重画柱子时使用邻域延伸兜底；隐藏区域仍较粗，当前只支持约2px的小视差，不支持自由相机移动。
- `scene-ready.foreground_url` 与背景一起保存至世界资产。新场景无该字段则不显示前景。咖啡馆原有桌沿遮罩保留。
- 多步骤场景准备允许最多5分钟；取消、过期结果和回访仍使用已有握手。

## 复现

`pnpm exec tsx scripts/prepare-foreground-samples.ts` 会调用真实图像服务生成样例（付费）。也可传 `porch` 或 `promenade` 只生成一个。

`pnpm exec tsx scripts/verify-foreground-browser.ts` 使用本地5173验证页和样例媒体，点击出发按钮，验证到达、图片加载、前景存在性、微视差和横竖屏。它不测试完整实时对话，也不打开麦克风。

结果在 `output/playwright/foreground/`：两个样例事件 JSON、横竖屏截图、前景隐藏/视差对照、`browser.json` 和测试日志。原始母图、遮罩提案、最终遮罩、补全输出及质量记录保存在对应媒体缓存。
