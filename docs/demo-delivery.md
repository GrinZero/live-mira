## 错误处理复录

需要已安装项目依赖、Playwright Chromium、ffmpeg，以及 `.env` 中真实语音/导演服务配置。会调用真实服务，无需用户麦克风或摄像头。确保 8796/5196 端口空闲，在项目根目录运行：

```bash
OUT_DIR=output/playwright/api-errors-rerun pnpm exec tsx scripts/record-error-handling.ts
```

脚本自动启动并关闭隔离后端、Vite 和故障代理，使用临时世界，不修改当前存档。默认输出目录自带时间戳；指定目录时应选新目录以保留历史证据。脚本断言真实服务模式、各故障触发、实际提示、场景保留/恢复与后续回答，保留原始录制和事件；成功后导出带故障章节标注的 MP4。
