# 持久世界与足迹地图 · 第一阶段实现

2026-09-19。对应 `interaction-plan-v1.md` 的世界状态、地点切换、地图与真实雷声部分。本文记录已实现范围，不代表整份互动方案已完成。

## 可体验的行为

- 进入后打开「足迹」，拖动、滚轮或双指缩放；画布只显示实际抵达过的地点和路径。选择旧地点可返回。
- 新场景先生成、预加载，再由服务器事务提交抵达；失败、超时、取消不会解锁新地点。迟到 ACK 不会重复增加访问次数。
- 回访加载保存的背景、前景和雨量/灯光状态，不重新生成同一地点。场景生成期间的旁白仅表示准备，不提前宣称抵达。
- 刷新、断线及服务器重启后，使用同一浏览器凭证恢复最近提交的世界。语音流和半途动作不恢复。重新开始创建新世界并保留旧存档；旧存档选择入口尚未提供。
- 地图区域异步生图、单独保存到固定画布坐标；失败使用地点原照片。新增区域不会重画旧区域。区域布局目前是稳定的访问顺序布局，不代表真实地理距离；尚未实现相邻区域无缝扩绘。
- 打开地图或切换中抑制主动发话；这不是完整的主动行为系统重构。
- 雷声改为独立的真实户外录音，闪电后延迟 0.8 秒播放，非循环、去重、不重叠，不进入人物口型分析器。来源和重建方法见 `assets/audio/SOURCES.md`。

## 状态与接入点

| 层     | 实现                                                                                                               |
| ------ | ------------------------------------------------------------------------------------------------------------------ |
| 协议   | `shared/world.ts` 定义地点、路径、环境和物件归属；媒体携带 travel_id 和 committed 标记                             |
| 存档   | `server/src/world/store.ts` 使用 SQLite 事务、事件唯一键与持久媒体文件；世界快照包含版本、近期 80 条交流与物件记录 |
| 生成   | `server/src/world/runtime.ts` 后台串行生成区域；有界重试，失败降级，不阻塞抵达                                     |
| 会话   | `server/src/session.ts` 管理临时切换、所有者恢复、取消、提交、环境和近期交流保存                                   |
| 客户端 | `directorClient.ts` 图片准备与抵达提交分离；`WorldMap.tsx` 提供可访问弹层及画布                                    |
| 回放   | `web/src/net/mock.ts` 保持回放音频，支持本次回放内发现和返回；不生成新地点、不提供跨刷新存档                       |

世界资产通过随机能力 URL 读取；数据库对浏览器凭证做哈希关联。没有账号系统或跨设备同步。实时连接仍使用单实例部署；持久媒体目录不能当临时缓存清理。

`WORLD_DATA_DIR` 默认 `data/worlds`，部署必须挂持久盘。SQLite 与媒体需要作为一份存档一起备份；运行中备份应使用 SQLite 一致性备份方式，不能只复制主数据库文件而遗漏 WAL。`MAP_IMAGES=0` 关闭地图付费生图并使用照片占位。

- 单独调用真实生图链路，以咖啡馆背景作为参考成功生成并持久化地图插画，产物在 `output/checks/world/generated-cafe.webp`。已检查画面；这不等于多区域接缝质量或全流程真实语音验收。

## 2026-09-19 场景体验复查与修正

用户指出转场走位怪异、地图没有可见内容后，重新录制了真实浏览器过程。确认旧转场把人物斜向位移、正弦摆腿、镜头拉远叠加在静止照片上；入场镜头随后再次推进，出现滑移、人物缩放和站在家具上的错觉。

本次将转场改为固定站位的转头示意与全遮挡切换。源场景保持原有取景，目的地镜头在遮挡期间直接切换到该场景的取景参数，人物不再沿未经标定的照片平面行走。这是适配现有照片场景的转场修复，不是已完成足部 IK 或真实导航。

地图首个咖啡馆区域现在直接使用已生成并检查的插画 `assets/bg/cafe_map.webp`，进入时晋升到存档。打开地图重新请求权威快照，布局完成和视口变化后全览已有区域；放大图块可见范围。失败图块仍显示原场景照片，并可在再次打开时有节制地重试生图。未同步时明确提示并提供重新同步入口。地点详情去掉内部镜头提示词。
