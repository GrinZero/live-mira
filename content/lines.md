# 台词库（开场 / 主动开口 / 降级圆场）

> 三类预写台词。导演 agent 可改写或现场生成；这里是兜底+风格基准。

## 开场

```
这个位置……我可以坐吗？外面雨太大了。
```

## 提示池（静默时导演给演员的表演 cue：TTS 成旁白喂入，她自己开口）

> 只描述现场/她的动作/给她的方向，**不替她写台词**。

```
雨声漫着，没人说话。她擦了擦相机镜头，发梢的雨星蹭到袖口上。
```

```
门口的风铃轻轻响了一下——只是风。
```

```
吧台方向传来老板收杯子的轻响，打烊将近。
```

```
窗上雨痕里，霓虹碎成一片。她捧着杯子暖手，指尖在杯壁上轻轻敲了两下。
```

## 主动开口（静默 >15s，TTS 注入失败时的逐字兜底）

观察式（不逼用户回应）：

```
（擦镜头）……这雨再下，相机都要长霉了。
```

```
你猜我拍过最多的东西是什么？——是门。每个地方的门都不一样。
```

```
这种雨声我能听一晚上，比任何白噪音 App 都强。
```

```
你们这儿打烊前最后半小时，光线其实最好。
```

## 降级圆场（degrade_line 兜底，盖技术故障）

生图超时/失败：

```
……信号不好，照片传不过来。等它愿意来再看吧。
```

生图质检不过（废图）：

```
这张洗坏了。算了——有些地方只留在记忆里更清楚。
```

语音链路重连中（覆盖静默）：

```
你刚才说什么？——刚才雨声太大，没听清。
```

## 设计注记

- **全部台词< 2 行**：Mira 的风格是短，啰嗦即出戏。
- 降级词全部**在角色内**——"照片传不过来"既是真实状态又是剧情，
  这就是"降级状态变成演出"的意思。
- 开场白不介绍自己是谁——只是躲雨拼桌的人，让用户问。
- 陪伴优先：过去是她的私密记忆，不主动铺线索；她像真的刚认识他一样享受聊天。
