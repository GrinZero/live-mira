# 生图风格模板（Seedream）

> 目标：**内容开放，摄影质感统一**。LLM/导演只产主题，服务端套固定风格层，
> 保证任何剧情走向出来的图都像同一个片子的截图。

## 模板

```
{scene_body}。细腻的电影摄影，35mm 胶片质感，协调而自然的光影和色彩。
忠实表现主体描述中的地点、物件、时间和天气，不擅自换成咖啡馆或雨夜。
画面干净，无 UI，无额外文字。
```

`{scene_body}` 由导演给主题后拼装，例如：

| 场景 key                             | scene_body                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `cafe_interior`（默认背景，预生成）  | 快打烊的咖啡馆内景，落地玻璃窗上雨痕密布，吧台上只剩一盏暖色吊灯，木桌椅与一台相机                |
| `street_outside`（门外）             | 咖啡馆门外的雨夜街道，积水路面反射霓虹，一把被风吹翻的伞，远处模糊人影，从玻璃内向外的视角        |
| `memory_photo`（照片内容，剧情驱动） | 一张宝丽来照片里的异国街景——{用户对话中提取的地点/线索}，照片边角有手指捏着的痕迹，怀旧的暖褪色调 |
| `hospital_corridor`（医院线）        | 深夜医院走廊，惨白顶灯与窗外雨夜的冷光，空座椅，尽头的自动门，安静而干净                          |
| `closing_time`（打烊）               | 打烊中的咖啡馆，倒扣在桌上的椅子，吧台只剩最后一盏灯，黑暗中雨声可闻                              |

## 管线参数

- `size`: `2016x1152`（实测出图档）；scene/foreground 走竖屏 1440x2560
- 质检：分辨率 + 非纯色方差检查 → 失败重试 1 次 → 仍失败走剧情化降级
- 缓存：`scene_key + 主题 hash` → 回访同场景秒切
- 前景板（kind=foreground）：场景落定后以**正在显示的那张底图**做 i2i，只在画面下缘加失焦前景元素；与底图上 2/3 做结构漂移校验（48×27 降采样 MAE>32 判错位），不过重试 1 次仍败 → self-band 兜底（前景层直接复用底图，零错位）。客户端只渲染底部羽化带 + blur，接缝被浅景深吃掉
- 水印：Seedream 自带"AI生成"角标（合规），demo 保留不裁

## 视频加分项（Seedance 2.5，可选）

剧情高潮（如推开门走入雨中）可用 `doubao-seedance-2-5-i2v`：
以当前场景图为首帧生成 3-5s 视频片段。仅当主线全稳、时间有余再做。
