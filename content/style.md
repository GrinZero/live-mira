# 生图风格模板（Seedream）

> 背景沿用默认咖啡馆的写实电影质感；相片、前景、事件编辑分别使用独立提示词。

## 背景材质模板

```
{scene_body}。与默认咖啡馆一致的写实电影场景，真实木材、玻璃与建筑材质，自然镜头景深，细腻的胶片质感，可信的空间尺度和柔和光照。不要二次元插画、赛璐璐或漫画线条。
忠实表现主题指定的地点、时间与天气；只有主题为雨夜时才使用暖琥珀灯光与冷蓝环境光、湿润反射，不给其他天气强加雨夜。
环境中不额外添加人物。无文字无UI。
```

`{scene_body}` 由导演给主题后拼装，例如：

| 场景 key                             | scene_body                                                                         |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| `cafe_interior`（默认背景，预生成）  | 快打烊的咖啡馆内景，落地玻璃窗上雨痕密布，吧台上只剩一盏暖色吊灯，木桌椅与一台相机 |
| `street_outside`（门外）             | 咖啡馆门外的雨夜街道，积水路面反射霓虹，一把被风吹翻的伞，从玻璃内向外的视角       |
| `memory_photo`（照片内容，剧情驱动） | 一张宝丽来照片里的异国街景——{用户对话中提取的地点/线索}，怀旧的暖褪色调            |
| `hospital_corridor`（医院线）        | 深夜医院走廊，惨白顶灯与窗外雨夜的冷光，空座椅，尽头的自动门，安静而干净           |
| `closing_time`（打烊）               | 打烊中的咖啡馆，倒扣在桌上的椅子，吧台只剩最后一盏灯，黑暗中雨声可闻               |

## 管线参数

- `size`: `2016x1152`（实测出图档）；scene 固定 2560x1440；foreground 跟随底图方向
- 质检：分辨率 + 非纯色方差检查 → 失败重试 1 次 → 仍失败走剧情化降级
- 缓存：`scene_key + 主题 hash` → 回访同场景秒切
- 水印：Seedream 自带"AI生成"角标（合规），demo 保留不裁

## 视频加分项（Seedance 2.5，可选）

剧情高潮（如推开门走入雨中）可用 `doubao-seedance-2-5-i2v`：
以当前场景图为首帧生成 3-5s 视频片段。仅当主线全稳、时间有余再做。

## 站位契约

`shared/scene-layout.ts` 是新背景提示词、裁切和人物相机的共同来源。stage2 缓存采用新的站位契约，历史图片保持原有取景。最终底图不保留占位人影；本版由 `server/src/scene-guide.ts` 生成实际布局参考图，紫红矩形预留身体净空，框底边中点标定地面接点，作为生图 API 的 image 输入。先按布局生成环境，再独立图编辑移除标记，清理后才发布；图编辑失败不会退回纯文字生成。提示词不能保证模型准确执行，仍需实图验收。

近距离陪伴取景：站位框高度为源图60%，人物约1.65米。框图、背景提示词、前端相机共同使用这一尺度；禁止远景小人构图。

新场景在生成前随机确定站位：横向中心在25%–75%，脚底在74%–84%，框高固定60%。参考框、提示词和渲染共享该位置，坐标写入版本化媒体URL，保存和回访不重新抽取。手机裁切根据人物安全边界调整；新场景渲染保持视口高度60%，超宽屏也不放大到越界。历史stage2场景仍按原有构图显示。

- 新场景暂不启用自动前景分离；默认咖啡馆保留原有桌沿遮罩。
